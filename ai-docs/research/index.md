# Research notes

The first research pass for polywright, 2026-10-11: five notes written by research agents from web sources, registries and probes of a local Blender 5.2.1. Each has a "Bottom line", dated sources and an "Open questions / unverified" list. Machine-specific details were generalised before publishing.

- [2026-10-11-reality-capture.md](2026-10-11-reality-capture.md): read for photogrammetry, splats, scanners, places from open data (parks into games and prints), cleanup after capture.
- [2026-10-11-generative-3d.md](2026-10-11-generative-3d.md): read for image-to-3D and text-to-3D models (open and hosted), licences, VRAM, reference sheets, texturing, retopology and rigging of generated meshes.
- [2026-10-11-blender-and-tooling.md](2026-10-11-blender-and-tooling.md): read for Blender 5.x API facts probed locally, MCP bridges, and the 3D tools per OS with versions.
- [2026-10-11-craft-and-academics.md](2026-10-11-craft-and-academics.md): read for modelling paradigms, topology, UVs and PBR, target checklists (games, print, video, business), and the 2024-2026 research front.
- [2026-10-11-ai-agents-and-3d.md](2026-10-11-ai-agents-and-3d.md): read for existing agent 3D tools and MCP servers, agentic 3D benchmarks, practitioner reaction, store AI-disclosure rules and the design recommendations polywright follows.
