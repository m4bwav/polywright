# pw.py command reference

`scripts/pw.py` (Python 3.9+, standard library only) prints one JSON object per command and exits 0 on success,
1 on a failed check or error, 2 on a usage error. `scripts/pw_bpy.py` is the Blender half: pw.py runs it as
`blender --background --factory-startup --python-exit-code 3 --python pw_bpy.py -- <action> <params> <result>`
(without `--python-exit-code` a Python error inside Blender still exits 0).

Back to [SKILL.md](../SKILL.md). Checked against Blender 5.2.1 LTS on Windows 11, 2026-10-11.

## Result semantics

`duel` reports clip duration in `seconds` (`frames / fps`), not elapsed runtime. Its successful result has no
`action` or `blender` fields; `--check` returns the same clip metadata without running Blender.

For Blender-backed `inspect`, `watertight` means no boundary or non-manifold edges after welding positions.
It does not certify face orientation or absence of self-intersections. `inside_out` uses the signed volume of
each object, so it can miss a single flipped face. Use `--topology` for `winding_mismatch`, then
`convert --fix-winding` to repair inconsistent winding.

## Finding tools

| Variable | Use |
|---|---|
| `POLYWRIGHT_BLENDER` | path to `blender` / `blender.exe`; otherwise PATH, then install folders (Program Files on any drive, Steam, `/Applications/Blender*.app`, `/snap/bin`, `/opt/blender*`), newest first |
| `POLYWRIGHT_BPY_PYTHON` | a Python that can `import bpy` (the PyPI `bpy` wheel needs exactly the Python Blender bundles: 3.13 for 5.2) |
| `POLYWRIGHT_COMFYUI` | comma-separated ComfyUI URLs for `gen`; default `http://127.0.0.1:8188` |

## Commands

| Command | Needs | What it does |
|---|---|---|
| `doctor [--host URL]` | nothing | Blender path and version, Python mesh modules, CLIs (gltf-transform, gltfpack, colmap, openscad, slicers, ffmpeg), ComfyUI hosts and their 3D checkpoints, and `can`: which commands will work |
| `inspect FILE [--fast] [--topology]` | Blender, else trimesh, else stdlib (GLB, binary STL) | triangles, objects, size, materials, images, UV-less objects, unapplied scale, armatures; boundary and non-manifold edges, parts, volume on welded positions (glTF/STL split vertices per face); `--topology` (Blender) adds tris, quads, n-gons, poles by edge count, flipped faces (winding mismatches), faces stacked on the same corners, loose edges and vertices, and UV texel spread (p95/p5) |
| `render FILE --out DIR [--views front,right,back,left,top,iso] [--color clay\|material\|texture] [--engine workbench\|eevee\|cycles] [--size 640]` | Blender | one PNG per view plus `sheet.png`; orthographic views report metres per pixel (compare with blueprints) |
| `spritecam BASES.json --out camera.json [--tiles 2] [--tile-px 48] [--tile-m 5] [--max-rms 4] [--like NAME]` | nothing | an orthographic sprite camera fitted from the ground diamonds (`groundBase` front, left, right corners, image pixels, y down) found anywhere in the JSON (a building registry): median yaw, elevation and pixels per tile over the sprites of that footprint that fit, the spread, and every sprite's own fit; `--like` takes one sprite's footprint centre |
| `sprite FILE --camera camera.json --out DIR [--passes beauty,clay,depth,normal,id,pos] [--frames N] [--frame-passes beauty,id,pos] [--scale K] [--hide PREFIX,...] [--samples 64] [--footprint-m X,Y] [--pos-extent 2.5] [--no-line] [--gpu]` | Blender (numpy and Pillow for the line pass) | the model through a sprite camera at canvas size x scale: lit beauty, clay, depth, camera-space normal, flat ID colour per part (scene property `sprite_parts`: name to object-name prefix), `pos.tif` (16-bit object coordinates of the visible surface: for parts built in their pivot's space, the point on the moving body), `line.png`, loop frames for the scene's `loop` property, and `sprite.json` with the projected `groundBase`, each `rings` entry's rim in pixels and the ID colours (linear; the PNG is sRGB) |
| `framecam PROBLEM.json [--out cameras.json] [--name framecam] [--top 3] [--max-evals 3000000]` | nothing | grid-searches perspective cameras (position, aim, lens; each a number or `[low, high, step]` under `search`) for a scene illustration: every point in `boxes` lands in its screen box (`x`, `y` fraction ranges, y down), every `keep_in_frame` point inside the frame (less `margin`), every `keep_out_of_bands` point outside each of `bands` (the UI's text areas), all in front; the biggest `size_measure` (two points' screen distance in pixels) wins. Prints the best as presets `<name>_1..n` (merged into `--out`), `passed_alone` per rule, `best_at_search_edge`; fails naming a rule no camera met |
| `scene FILE --cameras cameras.json --camera NAME --out DIR [--size 1280x720] [--passes clay,beauty,depth,normal,id] [--samples 48] [--hide PREFIX,...] [--keep-lights] [--sky R,G,B:R,G,B] [--no-line] [--gpu]` | Blender (numpy and Pillow for line and sky) | a scene through one perspective preset (`pos`, `target`, `lens_mm`, optional `sensor_mm`, `depth_near_m`, `depth_far_m`; `sun` and `sky` beside `cameras`): clay (Workbench), beauty (Cycles), depth (inverse distance, near white; the range measured by a ray grid unless the preset sets it), camera-space normal, id (flat colour per part of the scene property `scene_parts`, sky transparent), `line.png`, with `--sky` a `beauty_sky.png`, and `scene.json`: `rings` rims and hubs and `scene_points` projected to pixels, id colours as written (sRGB). Scripts that build scenes can import `sweep` and `ribbon` from `pw_scene.py` |
| `match FILE --out X.png --anchor-px X,Y --aim-px X,Y --aim-local=X,Y,Z [--anchor-local=X,Y,Z] [--still PIC] [--depth M] [--lens 35] [--horizon ROW] [--roll DEG] [--sun-dir X,Y,Z] [--hide BOX]... [--mask-add BOX]... [--grow 10] [--gpu]` | Blender (Pillow for `--still`) | the model rendered RGBA from a picture's camera: the anchor point (a grip) lands on one pixel at `--depth`, the aim point (a tip) exactly on another; with `--still`, also `<out>_paste.png` and a blend mask `<out>_mask.png`. Model forward +X, up +Z. Write negative coordinates as `--aim-local=-0.8,0,0` |
| `crowd --out DIR [--action march\|advance\|charge\|clash\|hold] [--action-b A] [--ranks 6 --cols 30] [--view side\|behind\|high] [--lens 50] [--move static\|push\|crane\|truck] [--size 832x480 --frames 81 --fps 16] [--passes depth,mist,mask,clay,pose] [--scatter N --scatter-gap 1.2 --scatter-depth 25] [--preview] [--save-blend]` | Blender (Pillow for pose and the sheet; videos through ffmpeg, else Blender's own FFmpeg) | two armies of low-poly soldiers with offset walk cycles; per frame: inverse depth (one range per shot), Mist on request (same range, near white, 16-bit), side mask, clay, OpenPose skeletons of figures taller than `--pose-min-px`; `<pass>.mp4`, `camera.json`, `joints.json`, `sheet.png`. `--scatter` adds about N standing figures per side behind the last rank as Geometry Nodes instances (in depth, mask and clay; no skeletons; none behind a camera that stands in that side's rear). Refuses sizes Wan cannot take unless `--any-size` ([crowd-blockouts.md](crowd-blockouts.md)) |
| `duel DUEL.json [--out DIR] [--preview] [--check] [--gpu] [--samples 4] [--any-size] [--save-blend]` | Blender (Pillow for pose and the sheet; videos through ffmpeg, else Blender's own FFmpeg; `--check` needs nothing) | two posed fighters in a set (a .blend, a room script or a floor) through the shot's camera, from a JSON file of marks, keyed poses, blades and thrown props; per frame: clay (twice the size), its Canny, inverse depth with real and with thick blades, COCO-18 joints with face points turned from the lens left out; `<name>_<pass>.mp4`, `joints.json`, `camera.json`, `sheet.png`; `in_frame` per fighter at the first and last frame. Default out `<file folder>/<name>/` ([crowd-blockouts.md](crowd-blockouts.md), "Two fighters") |

| `lods IN --out DIR [--ratios 1,0.5,0.25,0.1]` | Blender | `<name>_LOD0..n` files by decimation |
| `printable IN OUT.stl --size-mm N [--size-axis longest\|height\|width\|depth] [--wall-mm 1] [--voxel-mm V] [--base-cut-mm 0.6] [--drop a,b] [--up y] [--seal-mm 1] [--hollow]` | Blender | any mesh to one watertight solid: drop parts, scale, thicken open shells inward, voxel remesh, keep the largest part, fill a hollow shell's inside, flat base, decimate, clean |
| `union IN OUT [--solver manifold\|exact] [--voxel-fallback MM]` | Blender 4.5+ | boolean-union the closed shells of a file; falls back to EXACT when Manifold silently drops operands |
| `check FILE --target T [--real-size-m X] [--thickness-samples N] [--no-thickness]` / `check --list` | as inspect | rules from [targets.json](targets.json): triangles, materials, texture size, UVs, watertight, parts, bed size, unit sanity, wall thickness (Blender); game, web and AR targets also warn on flipped faces, stacked faces, n-gons (game) and UV texel spread over 2.5 (Blender) |

| `mark FILE --out X.glb [--recolour H,S,V --from-hue LO,HI --min-sat S --min-val V] [--erase white\|red] [--text T --colour R,G,B --font F] [--height-m H \| --longest-m L]` | Blender (numpy) | fix a generated figure: base colour moved to measured photo values, a smeared painted marking erased on the head's front UV islands, a clean one put on as a thin text mesh, real size; the fixed texture lands beside the output |
| `lineup --layout L.json --out DIR [--frames 107,362 --fps 24 --card C] [--preview]` | Blender (ffmpeg for videos) | figures on a table with teams on fixed sides: colour, clay, inverse depth, team mask, `lineup.json` with screen boxes and `left_to_right`, looped `control_<card>_<pass>_<n>f.mp4` |
| `new DIR --name N --kind K --route R --targets a,b` | nothing | the asset folder and `manifest.json` ([contract.md](contract.md)) |
| `manifest DIR [--add-source URL --licence L --author A --what W] [--add-output PATH --target T --inspect] [--add-tool N --tool-version V] [--review RENDER --verdict V --by B] [--status S] [--validate]` | nothing | record provenance, outputs and reviews; validate licences, files on disk and hashes. A relative `--add-output` or `--review` path may be written from inside the asset folder |
| `bpy SCRIPT [--blend FILE] [--timeout S] [-- args]` | Blender | runs your bpy script headless; returns condensed output and the traceback, not 300 lines of Blender log. pw.py's options may come before or after SCRIPT; everything after `--` goes to the script |
| `gen --image FRONT [--left --back --right] --out X.glb [--turbo] [--seed N] [--octree 256]` | ComfyUI with Hunyuan3D-2 checkpoints | built-in Hunyuan3D-2 single or multi-view graph; background removal (rembg if installed), padding; writes `X.gen.json` with host, model, seed, licence note |
| `gen --image IMG --workflow W.json --out X.glb [--set NODE.input=VALUE] [--save-api G.json]` | ComfyUI with the workflow's nodes | any workflow, API format or as saved by the editor (a template file works as is: converted with the host's node definitions); picks a host that has every node; a rejected graph prints ComfyUI's node_errors |
| `place --bbox S,W,N,E \| --center LAT,LON --size-m M --out DIR [--dem auto\|usgs\|terrarium\|flat] [--res M] [--print-mm N --exaggerate 1.5 --base-mm 3 --print-roads]` | network (Overpass, elevation) | `scene.glb` (terrain coloured by land use, buildings with OSM heights, roads, paths, waterways, trees), `place.json` with counts and credits, and a print tile |

## Reading results

- `ok: false` always carries `error`; Blender failures add `log` or `traceback` (condensed).
- `inspect` sizes are Blender units: metres unless the source used other units. An STL in millimetres reads
  1000 times too big; `check --real-size-m` flags it.
- `render` returns `sheet.path`; read that one image.
- `check` returns `status` pass, warn or fail and one row per rule. For targets with `min_feature` (prints) and
  Blender found, it measures wall thickness: `inspect.thickness` has `thin_fraction`, `thinnest`, `p05` and up
  to five `thin_spots`; `--thickness-samples N` (20,000) and `--no-thickness`. Without Blender the row is
  `unchecked`: look at the render.
